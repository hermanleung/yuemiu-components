# yuemiu-components

Copy-paste ready front-end effect components (loaders, buttons, cards, text effects, backgrounds) — **100% free, MIT licensed**.

> This is the open-source sample pack of [**yuemiu.cn**](https://yuemiu.cn/) (粤喵组件库). Browse all **138 components** with live demos and code on the site.

## What's inside

Open any `examples/<name>/index.html` in a browser — each file is fully self-contained (HTML + CSS + JS, zero dependencies, no build step).

## Features

- Pure HTML/CSS/JS — copy the code into any project, no framework required
- Each effect ships with a clean, self-contained demo page
- Category coverage: loaders · buttons · cards · text effects · backgrounds · 3D · micro-interactions
